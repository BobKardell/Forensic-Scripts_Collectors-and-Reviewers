Drop Python tools into this folder. The launcher reads metadata without executing the file.

Recommended header:

# FFT_TOOL
# TITLE: Example Tool
# ID: example_tool
# CATEGORY: Plugins
# VERSION: 1.0
# DESCRIPTION: Description shown by the launcher.
# ICON: ◆
# PASS_CASE_ARGUMENTS: false

Use CATEGORY: Analysis Tools to place a script under Analysis Tools.
Hex Editor scripts are also automatically placed there when their IDs match the built-in hex IDs.
